# FinFET (Fin Field-Effect Transistor)

FinFET is a non-planar, or "3D", transistor used in modern semiconductor device fabrication. It gets its name from the thin "fin"-like silicon structure that forms the channel, which is wrapped around by the gate from multiple sides.

## 🔍 Why FinFET?

Traditional planar MOSFETs struggle with power leakage and performance at smaller nodes (below 22nm). FinFETs overcome these issues by improving gate control and reducing short-channel effects.

## ✅ Key Features

- Multi-gate structure for better electrostatic control
- Higher drive current
- Lower leakage current
- Scalable for advanced nodes (e.g., 14nm, 7nm)

## 📚 Applications

- Mobile processors
- High-performance computing
- Low-power IoT devices

Used extensively by Intel, TSMC, and Samsung in modern chip manufacturing.
