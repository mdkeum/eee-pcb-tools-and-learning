# EEE & PCB Design Tools and Learning Repository

This repository is a personal collection of tools, resources, and learning materials related to Electrical and Electronics Engineering (EEE) and Printed Circuit Board (PCB) design. It covers theoretical notes, practical simulations, tutorials, and tool-specific guides for various EDA software.

## 🔧 Topics Covered

- **FinFET and advanced transistor technologies**
- **PCB Design Tools**
  - KiCad
  - Altium Designer
  - Eagle
- **Simulation Tools**
  - LTspice
  - Multisim
- **Microcontrollers & Embedded Systems**
  - Arduino, STM32, ESP32
- **Analog and Digital Circuit Design**
- **Datasheets, Reference Designs, and Notes**

## 📂 Folder Structure

Each topic is organized into separate folders for ease of navigation. Contributions, issues, and suggestions are welcome!

## 🧠 Why this Repo?

- To track personal learning and progress
- To provide a central reference for common tools and techniques
- To help others learn by sharing real examples and notes
