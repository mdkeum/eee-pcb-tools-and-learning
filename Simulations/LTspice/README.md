# LTspice - Circuit Simulation

LTspice is a powerful, free SPICE-based simulator developed by Analog Devices.

## 🧪 What You Can Do

- Simulate analog and digital circuits
- Analyze frequency, time, and transient response
- Perform DC sweeps, parameter sweeps, and Monte Carlo analysis

## 📥 Download

- https://www.analog.com/en/design-center/design-tools-and-calculators/ltspice-simulator.html

## 📝 Example Simulations

- RC filters
- Op-Amp circuits
- MOSFET switching
