# KiCad - Open Source PCB Design Tool

KiCad is a free, open-source software suite for electronic design automation (EDA). It helps in creating schematics and designing PCB layouts.

## 🛠️ Features

- Schematic capture
- PCB layout editor
- 3D viewer
- BOM generation

## 🚀 Getting Started

1. Download KiCad: https://kicad.org/download/
2. Follow the official getting started guide: https://docs.kicad.org

## 📦 Useful Libraries

- Digi-Key symbol & footprint library
- SnapEDA plugin
- KiCad StepUp tools for 3D models
